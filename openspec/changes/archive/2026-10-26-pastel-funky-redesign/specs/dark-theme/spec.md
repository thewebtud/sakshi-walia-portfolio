# dark-theme Specification

## REMOVED Requirements

### Requirement: Dark theme is the only theme
**Reason**: The site moves to a single light pastel theme (see `pastel-theme`).
**Migration**: Use the "Light pastel theme is the only theme" requirement in `pastel-theme`.

### Requirement: No theme control
**Reason**: Carried over unchanged in intent to `pastel-theme`.
**Migration**: Use the "No theme control" requirement in `pastel-theme`.

### Requirement: Browser chrome matches dark theme
**Reason**: The browser chrome now reflects the light pastel background.
**Migration**: Use the "Browser chrome matches the pastel theme" requirement in `pastel-theme`.

### Requirement: Dark theme meets contrast and motion guarantees
**Reason**: Contrast and focus guarantees now apply to the pastel theme.
**Migration**: Use the "Pastel palette with ink text" and "Distinct pastel section tints" requirements in `pastel-theme`.
